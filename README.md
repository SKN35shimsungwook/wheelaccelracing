# 🏎️ 휠 액셀 레이싱 (Streamlit 버전)

마우스 휠 = 가속/브레이크, WASD = 조향, Space = 드리프트인 탑다운 레이싱 게임을
**Streamlit**으로 감싸서 파이썬 프로젝트처럼 배포할 수 있게 만든 저장소예요.
`main.ipynb` 노트북 하나만 열어서 위에서부터 순서대로 실행하면 `game.html` / `main.py` /
`requirements.txt`가 전부 자동으로 생성돼요.

## 1. 무슨 게임이에요?

- HTML5 Canvas + 순수 JavaScript로 만든 탑다운 드리프트 레이싱 게임이에요.
- **마우스 휠 위로 굴리기**로 가속하고(계속 굴려야 속도가 유지돼요 — 페달처럼 스프링백),
  **아래로 굴리면** 브레이크/후진이에요.
- **A / D**로 좌우 조향, **W / S**는 보조 가속/브레이크예요.
- **Space**(핸드브레이크)를 누른 채 코너를 돌면 드리프트가 걸려요. 슬립 각도와 속도에 따라
  콤보 점수가 쌓이고, 손을 떼는 순간 쌓인 점수만큼 부스트가 터져요.
- 뒷바퀴에는 스키드 마크가 남고 드리프트 중엔 스모크 파티클이 뿜어져 나와요.
- 3랩을 완주하면 총 기록과 베스트 랩이 표시돼요. **R**로 언제든 재시작할 수 있어요.

## 2. 왜 Streamlit으로 감쌌어요?

이 게임은 **1초에 수십 번씩 물리 연산**(가속·그립·드리프트·충돌 판정)을 하고, **마우스 휠과
키보드를 실시간으로** 받아야 하는 액션 게임이에요. 그런데 Streamlit은 원래 "위젯을 조작하면
파이썬 코드를 처음부터 다시 실행하는" 방식이라, 이런 빠른 액션 게임을 파이썬 코드로 직접
재구현할 수는 없어요.

그래서 택한 방법이: **게임은 원래 그대로(HTML/JavaScript) 두고, 그 게임 전체를 통째로 Streamlit
페이지 안에 "끼워 넣기"**예요. `st.components.v1.html()`이 Streamlit 페이지 안에 다른 웹페이지를
통째로 넣을 수 있는 작은 창문(iframe)을 만들어주고, 그 안에 `game.html`을 그대로 띄워요. 그럼
게임의 움직임과 손맛은 원본이랑 똑같이 유지되면서, 배포·페이지 구성은 파이썬(Streamlit) 방식으로
할 수 있어요. 즉, **파이썬은 게임을 담는 "액자"만 만들고, 게임 자체는 원래 방식(JavaScript) 그대로
돌아가요.**

## 3. `main.ipynb`는 왜 있어요?

`main.ipynb`가 이 저장소의 **소스**예요. 노트북을 열어서 셀을 위에서부터 순서대로 실행하면:

1. `game.html` — 게임 본체
2. `main.py` — Streamlit 페이지
3. `requirements.txt` — 의존성 목록 (streamlit 하나뿐)

세 파일이 저장소 안에 그대로 생성(또는 최신 내용으로 갱신)돼요. 이미 세 파일이 있는 상태에서
노트북을 다시 실행해도 내용이 동일하게 갱신될 뿐이라 안전해요.

## 4. 내 컴퓨터에서 직접 실행해보기

```bash
# 1) (선택) 노트북을 실행해서 game.html / main.py / requirements.txt를 생성·갱신
jupyter nbconvert --to notebook --execute --inplace main.ipynb

# 2) 패키지 설치 후 실행
pip install -r requirements.txt
streamlit run main.py
```

이미 `main.py`와 `game.html`이 저장소에 들어있으니, 노트북을 다시 실행하지 않고 바로
`streamlit run main.py`만 해도 게임이 실행돼요.

## 5. 파일 구성

```
wheelaccelracing/
├── main.ipynb         # 소스 노트북 — 실행하면 아래 3개 파일을 생성/갱신함
├── main.py             # Streamlit 페이지 (제목, 설명, 게임을 끼워 넣는 코드)
├── game.html            # 진짜 게임 본체 (Canvas + JS)
└── requirements.txt     # 필요한 파이썬 패키지 목록 (streamlit 하나뿐)
```

- **A / D** : 좌우 조향, **W / S** : 보조 가속/브레이크
- **Space** : 핸드브레이크(드리프트) — 콤보를 쌓았다가 떼면 부스트
- **R** : 재시작 · 3랩 완주 시 총 기록과 베스트 랩 표시
